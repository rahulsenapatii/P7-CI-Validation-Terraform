# CI Validation for Terraform

[![Terraform CI Validation](https://github.com/rahulsenapatii/P7-CI-Validation-Terraform/actions/workflows/terraform-ci.yml/badge.svg)](https://github.com/rahulsenapatii/P7-CI-Validation-Terraform/actions/workflows/terraform-ci.yml)

Automated CI pipeline using GitHub Actions to run terraform fmt -check, terraform init -backend=false, and terraform validate on every push to main.
